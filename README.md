# 个人衣橱与穿搭日记

这是“个人衣橱与穿搭日记”微信小程序实训项目。阶段1静态原型和阶段2数据库已完成；原生小程序及Express工程已建立，P3-02注册、登录、当前用户及昵称资料功能已实现。当前验收/版本状态见下方进度及P3-02执行记录。

已确认主风格为韩系日常女装，围绕短款针织、叠穿、牛仔和彩色配饰准备，强调版型、图案和搭配变化。使用微信开发者工具本地演示，没有日期限制。技术栈为原生微信小程序、JavaScript、Node.js Express、MySQL。
