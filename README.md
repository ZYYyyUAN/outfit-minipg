# 个人衣橱与穿搭日记

这是微信小程序实训项目的前序准备目录。2026年11月6日已按确认的韩系日常方向更新24张完整单品主图、7个分类、8套示例搭配和12篇演示日记，并记录来源和本机环境。替换22张图片，保留2张完整鞋包图片。尚未创建小程序或后端业务代码。

已确认主风格为韩系日常女装，围绕短款针织、叠穿、牛仔和彩色配饰准备，强调版型、图案和搭配变化。使用微信开发者工具本地演示，没有日期限制。计划技术栈为原生微信小程序、JavaScript、Node Express、MySQL。

## 验证准备结果

在本目录运行：

```powershell
node tools/verify-preparation.mjs
```

该脚本不连接数据库、不安装依赖、不启动服务。它核对图片文件、来源记录、衣物与搭配及日记的关联、日期唯一性和统计样例。

图片来源为CHERRYKOKO官方商品页和Pexels，使用记录详见 assets/SOURCES.md。品牌商品图按本地实训参考登记，未获单独再分发授权。演示日记为虚构样例；唯一附图是同款针织穿着参考，不表示真实用户自拍。没有附图的日记保留空照片字段，界面使用所选衣物缩略图展示。
