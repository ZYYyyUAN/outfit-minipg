## 演示步骤

1. 衣橱点击新增衣物，选择JPEG/PNG、填写名称/分类/颜色/季节，保存后进入新详情。
2. 返回衣橱并切换“我的”，在用衣物变为25；再进入搭配新增，输入名称和场景。
3. 选择多件衣物，切换搜索和分类，确认已选不丢失；确定后上移、下移或移除，再保存搭配。
4. 重新编辑搭配并更改组合，再去日记查看原有日期，历史衣物集合仍保持。
5. 在详情归档/恢复，核对列表范围、在用数量与关联；修改表单后取消，分别选择继续编辑和放弃。
6. 刷新页面，样例恢复24/8/12，本地临时图片和临时ID不再保留。
