# 少女衣橱素材调整方向

2026年11月5日，用户反馈首批素材款式过于基础，不符合希望呈现的少女衣橱。当时保留首批24张图片用于数据和功能验证，并重新筛选视觉素材；后续采用结果见文末。图片完整性检查通过不等于用户已接受选图风格。

用户随后明确选择“韩系日常：短款针织、叠穿、牛仔、彩色配饰”。该方向现为选图基线。

## 调整原则

先按款式、搭配效果和图片完整度筛选，再核对图片来源和使用条件。不能仅因为通用图库容易下载，就让整套衣橱只有基础T恤、纯色开衫、牛仔裤和运动鞋。

增加有明确设计细节的韩系日常候选：短款绞花针织、菱格或条纹开衫、衬衫领与袖口叠穿、背心叠穿、拼色长袖、花纹短外套、桶型与微喇牛仔、层叠半裙、彩色格纹围巾、软肩包和帽饰。基础色与亮色配饰搭配，不把少女风简单等同于全部粉色。

每个候选优先保留完整正面单品图及对应整套穿搭图；能追溯到同一件商品或衣物。局部面料图只作为详情补充，不再优先用于衣橱主图。大量不同人的半身照片也不适合作为单品主图。
