# 01 需求分析

个人衣橱与穿搭日记面向个人整理衣物、组合搭配和回看穿着记录。目标是形成衣物资料、搭配方案、按日期保存的穿着与统计闭环，在微信开发者工具本地演示。

范围包含注册登录、昵称头像、分类及鉴权图片、衣物筛选维护归档、搭配有序组合、日历日记及统计。不包含AI推荐、天气、社交、支付或公网部署。

10个业务页为衣橱列表、衣物详情、衣物编辑、搭配列表、搭配详情、搭配编辑、日记日历、日记详情、日记编辑、统计。登录、注册、资料及我的入口另计。覆盖实训任务书至少8个数据库功能页的设计要求；实现与原生实测分开说明。

用户只读写本人业务和图片。归档保留历史关联；搭配/日记选取1～20件有序、不重复的本人衣物。日记同日仅一篇，不允许未来日期；来源搭配只作来源，日记保存独立清单。统计随改记、删记重新计算。API使用真实数据库整数ID，样例逻辑ID只用于导入映射。

非功能要求包括scrypt密码摘要、会话撤销、所有权隔离、参数校验、事务一致性及图片完整解码。成功上传文件不因取消草稿自动删除。
