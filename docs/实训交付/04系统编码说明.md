原生微信小程序前端、JavaScript ES模块/Express后端、mysql2访问MySQL。依赖以[package.json](../../server/package.json)及锁文件为准，无ORM或新增框架。

| 位置 | 职责 |
| --- | --- |
| miniprogram/pages、utils | 页面生命周期、请求、会话、鉴权图片和跨页状态 |
| server/src/app.js、routes、middleware/auth.js | 路由入口、统一响应与令牌认证 |
| server/src/services | account/media/clothes/outfits/diaries/statistics业务 |
| server/src/config.js、db.js、index.js | 配置、连接探针、启动关闭 |
| shared/password.mjs | scrypt编码与验证 |
| database、assets、data | DDL/恢复工具、来源素材与固定样例 |

客户端使用相对API路径，会话保存token及过期时间，启动向服务端确认，退出须成功撤销。服务端存令牌摘要、固定7天有效，同账号新登录替代旧会话，密码和token不入公共证据。

上传由Multer接收、Sharp完整解码JPEG/PNG，保存稳定本人路径；读取需Bearer鉴权。客户端带头下载到临时路径展示，资料保存稳定引用。取消/替换不删除成功上传文件。

入口校验参数，service检查所有权和业务约束。outfits.js和diaries.js对主行/明细事务保存，唯一冲突转标准业务错误，未知错误交统一处理。statistics.js从独立日记明细计算，无预累计缓存。具体修复见[调试记录](05系统调试记录.md)。

P7未改业务源码，仅整理文档、忽略规则及证据。外来P5辅助脚本不是发布依赖。本轮最小HTTP临时脚本执行后移除，操作清单见[冒烟JSON](../evidence/P7/run-20261117-delivery/smoke.json)。

AI使用：用户负责需求取舍、授权和既有人工操作；AI协助方案、实现、素材整理及自动验证。本轮未做新原生验收，不编造全程模型或成员工作量。成员实际分工：**待填写**。
