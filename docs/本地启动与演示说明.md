# 本地启动与演示说明

适用阶段：P3-01基础工程。原生页面目前仅四入口骨架和本地健康检查；登录、衣物等业务尚未接入。静态原型及已有数据库样例仍独立保留。

## 后端配置与启动

本机Node为24.16.0，npm 11.14.1。后端使用独立server包，Express 5.3.0、mysql2 3.24.6及package-lock固定依赖。数据库结构及导入工具不重跑。

在PowerShell中运行：

```powershell
Set-Location -LiteralPath 'Z:\outfit\personal-wardrobe\server'
npm ci --no-audit --no-fund
npm start
```

启动前准备server/.env（本机已通过隐藏输入准备，Git忽略）或完整进程环境。键见.env.example：PORT、PUBLIC_BASE_URL、DB_HOST、DB_PORT、DB_NAME、DB_USER、DB_PASSWORD、UPLOAD_ROOT。进程环境优先；PORT默认3000，其余必填。示例没有可用数据库凭据，应在本机填写或通过隐藏输入注入，不能将密码粘贴到聊天/命令参数。

当前origin为http://127.0.0.1:3000，健康地址为http://127.0.0.1:3000/api/health。启动先只读确认MySQL目标与7表再监听，分别输出database-connected和http-listening。health只表示HTTP进程可响应，返回`{"data":{"status":"ok"}}`，不返回数据库或账号详情。

UPLOAD_ROOT的./uploads相对server目录解析，本机为Z:\outfit\personal-wardrobe\server\uploads。正式用户目录users/11与回滚遗留目录users/10各25张，不移动、覆盖或清理。不公开静态/uploads路径；鉴权读取留P3-03。

端口占用时程序报告EADDRINUSE并关闭本轮连接池，不自动改端口或停止占用者。先检查实际进程，确定新端口后同步PORT、PUBLIC_BASE_URL和miniprogram/config.js。数据库库名固定wardrobe_demo；不得因连接失败建替代库、清表或重新导入。

## 小程序导入与页面

导入根为Z:\outfit\personal-wardrobe\miniprogram，不是整个仓库。复制project.config.example.json为本机project.config.json，配置本项目实际可用AppID或工具明确支持的本地模式。实际项目配置与project.private.config.json均忽略，不提交账号信息或本机工具设置。

四个tab依次为衣橱、搭配、日记、我的。前三页明确功能待开发；我的页明确未登录，只有“检查本地连接”用于本阶段调用验证。小程序config.js中的apiBaseUrl为http://127.0.0.1:3000/api，按钮仅追加/health，不能重复/api。

在本项目开发者工具里确认基础库、项目编译及本地网络访问设置。实际身份/工具条件和截图以P3-01执行记录为准，不能用其他项目或浏览器预览代替。

本机实际工具为2.02.2609250 Stable，基础库3.18.0，本项目AppID由用户在本机导入配置。新版不接受旧touristappid占位值，其他机器应配置自身可用身份；不要直接把模板占位值当成可编译配置。工具服务端口按用户要求保持关闭，UI验收由用户手动执行，脚本不要求开启它。

演示顺序为：启动后端→编译本项目→连续切四tab→我的页检查成功→Ctrl+C停止后端→再次检查失败且按钮恢复→重启后端→手动再试成功。所有结果仅代表开发者工具本地模拟，不表示手机真机或公网部署通过。

## 测试、只读复查和关闭

```powershell
Set-Location -LiteralPath 'Z:\outfit\personal-wardrobe\server'
npm test
npm run verify:foundation -- --run-id 'manual-new-run-id'
```

test包括配置和HTTP测试，以及需要当前本机数据库配置的端口占用启动测试；不执行数据库写入。verify需要后端已启动和本机数据库配置，只读核对两条连接会话、7表、样例及起止文件保护，并请求现有health。runId应使用新的ASCII字母/数字/短横线/下划线，不覆盖旧证据。

正常关闭后端使用启动终端中的Ctrl+C，等待closed，再确认3000端口释放。不要关闭或重启本机MySQL服务来模拟故障。需要复现连接失败时，使用测试提供的未监听回环端口夹具；不要试错实际账号密码。

本次后端为前台终端进程，聊天/终端会话结束后可能停止；需要演示时在本机终端运行npm start并保持该终端打开。持久后台启动被自动审批拒绝，本次没有交付后台服务安装或自启配置。

原型仍可从项目根提供静态服务并访问/prototype/，原生四入口不读取原型演示JSON。P3-01不会创建登录态、更新样例或开放图片访问；P3-02继续认证与资料，P3-03继续文件和鉴权。
