## 本机复查与凭据输入

从项目根运行`npm --prefix database ci --ignore-scripts --no-audit --no-fund`恢复锁定依赖。工具无参数只显示帮助，不连接数据库；三种模式固定，不接受任意库名。

以下脚本隐藏读取密码，只供给本次进程，不把密码写入命令参数、文件、历史或Git；使用已经确认的账号，不猜密码。替换runId为新的ASCII标识，保留旧轮次。

```powershell
Set-Location -LiteralPath 'Z:\outfit\personal-wardrobe'
$env:DB_HOST = '127.0.0.1'
$env:DB_PORT = '3306'
$env:DB_USER = 'root'
$env:DB_NAME = 'wardrobe_demo'
$env:P202_RUN_ID = 'manual-new-run'
$p202Secure = Read-Host 'MySQL password' -AsSecureString
$p202Ptr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($p202Secure)
try {
    $env:DB_PASSWORD = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($p202Ptr)
    node database/verify-schema.mjs --preflight
    if ($LASTEXITCODE -ne 0) { throw '预检失败' }
    node database/verify-schema.mjs --structure
    if ($LASTEXITCODE -ne 0) { throw '结构核对失败' }
    node database/verify-schema.mjs --constraints
    if ($LASTEXITCODE -ne 0) { throw '约束核对失败，查看回滚结果' }
} finally {
    [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($p202Ptr)
    Remove-Item Env:\DB_PASSWORD
    $p202Secure.Dispose()
}
```

--preflight/--structure只读业务表；--constraints仅在7表全空且结构完全匹配时执行可回滚DML，并在重连后核对零行。参数缺失或未知模式失败；无密码配置时明确失败，不试空密码。重复验证会消耗自增值，不能在P2-03导入后继续运行夹具模式。

schema.sql仅用于确认无表、归属正确的目标状态；现库已建，不重跑。DDL非整体事务，错误时记录已成功对象，不自动删库或清表。不得使用其他业务库作验证目标。
